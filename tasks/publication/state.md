# Recipe publication state

The recipe's clean snapshot contains usable fixed-K5 profiles and all recorded
acceleration findings. Build/launch behavior, runtime patches, clients and raw
measurement files are unchanged. The `recipe-1m-k5` tag identifies the clean
recipe checkpoint. See [snapshot provenance](../../docs/provenance.md).

Original combined history, the prior research branch, split inventories and the
original rollback tag are maintained in the separate private adaptive repository.
History-separation administration is recorded there. The recipe remains private;
public visibility is a separate step after checking GitHub's cached-history
boundary. No runtime rebuild, new GPU test or public release is claimed here.

See [repository boundaries](../../docs/repository-boundaries.md),
[recipe verification](../recipe-snapshot/verification.md), and
[primary performance findings](../../docs/performance-scorecard.md).
